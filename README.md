# Yandex Final Project: Task Scheduler

Веб-сервер для управления задачами (ToDo List) с поддержкой повторений, аутентификацией и API.

## Выполненные задания со звёздочкой
- [x] Поддержка определения порта из переменных окружения.
- [x] Поддержка указания файла базы данных через переменные окружения.
- [x] Поддержка правил повторения `w` (weekly) и `m` (monthly).
- [x] Поиск задач по заголовку/комментарию и дате.
- [x] Аутентификация через JWT токены.
- [x] Docker-образ для деплоя.

## Локальный запуск

1. Установите зависимости:
   ```bash 
   go mod tidy
2. Переименуйте файл .env.example или создайте файл .env
3. Запустите сервер:
    ```bash 
    go run .
4. Откройте браузер:
    ```bash
    http://12.0.0.1:7540

## Локальный запуск Docker file
1. Соберите образ docker:
    ```bash 
   docker build -t yandex-final .
2. Запустите контейнер:
    ```bash 
    docker run -p 7540:7540 -v $(pwd):/root/data -e TODO_DBFILE=/root/data/scheduler.db -e TODO_PASSWORD=00000  yandex-final
